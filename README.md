# השלמות — זוהר צפוני 2021–2025

סקיצת p5.js לתרגיל "ממספרים למשמעות" בקורס עיצוב אלגוריתמי.

**השאלה:** הזוהר הוא דלת שנפתחת רק כשכמה תנאים נפגשים. כמה פעמים היא באמת נפתחת, וכמה פעמים מישהו בכלל רואה אותה?

**התשובה בקצרה:** הזוהר קיים כמעט תמיד איפשהו. מה שנדיר הוא הרגע שבו הוא פוגש עין. בחמש שנים ובחמש ערים, כל התנאים התקיימו יחד רק בפחות משעה וחצי מכל אלף שעות.

## להרצה
- `index.html`: ‏"השלמות", כדור הארץ בתלת־ממד.
- `flow/index.html`: ‏"מערכת הזרימה של הזוהר". השאילתה המרכזית מוצגת כזרם שמסונן שלב אחרי שלב.

פותחים בדפדפן, ואין צורך בהתקנה. ספריית p5.js ומפת העולם נטענות מ‑CDN.

## הייצוג
כדור הארץ בתלת־ממד, וחמש שנים רצות בערך ב‑100 שניות. כל תנאי לזוהר הוא שכבה:

| שכבה | נתון |
|---|---|
| שמש | מספר כתמי השמש לפי חודש (GFZ) |
| רוח השמש, חזית ההלם, המגנטוספירה והזנב | מבנה פיזיקלי. הגבול נדחס לפי Kp |
| חגורות ואן אלן | חלקיקים לכודים שנודדים סביב כדור הארץ |
| טבעת הזוהר | ‏Kp כל 3 שעות (GFZ). הצבעים לפי גובה: ורוד (חנקן, כ‑100 ק"מ), ירוק (חמצן, 557.7nm), אדום (חמצן, 630nm), סגול (‎N₂⁺‎) |
| חושך וירח | חישוב אסטרונומי |
| עננים | ‏ERA5 דרך Open‑Meteo |
| עמוד השערים מעל כל עיר | חושך · פעילות · שמיים בהירים · בלי ירח · סערה |

**רגעי השלמות:** כשסערה של Kp 7 ומעלה פוגעת בעיר שנמצאת בחושך עם עננות של 30% או פחות, הזמן עוצר. המצלמה צוללת אל המקום, ומסביב נדלקות ההשפעות עם הנתונים האמיתיים של אותה שעה.

**הדרום:** הכפתור "דרום ⇅" מציג את הזוהר הדרומי ושלוש ערים: הובארט, קווינסטאון ואושואיה.

## השאילתות
1. **שנים:** כמה סערות היו בכל שנה, והאם הן עוקבות אחרי כתמי השמש? השיא בכתמים היה ב‑2024, אבל השיא בסערות הגיע ב‑2025.
2. **עונות:** באילו חודשים יש הכי הרבה פעילות? מרץ ואפריל, ספטמבר ואוקטובר. זה אפקט השוויון.
3. **ערים:** מתוך שעות הפעילות בחושך, באיזה אחוז השמיים היו גם בהירים? פיירבנקס 30%, טרומסה 6%.
4. **סערות חזקות:** בכמה מ‑56 בלוקי הסערה של Kp 7 ומעלה מישהו יכול היה לראות?
5. **טמפרטורה:** האם לילות בהירים קרים יותר? כן, ב‑1.7 עד 4.7 מעלות.
6. **משפך:** כל השעות ← חושך ← פעילות ← שמיים בהירים ← בלי ירח ← סערה.

## נתונים (`data/`)
- `aurora_5y_monthly.csv`: חודש × עיר, 2021–2025. כולל כתמי שמש, F10.7, ספירות Kp, שעות חושך, שעות בהירות ושעות בכל רמה.
- `aurora_5y_storms_kp7.csv`: כל בלוקי ה‑Kp 7 ומעלה, ומה היה בשמיים בכל עיר.
- `aurora_crossed.csv`: שבוע אחד, 17–25.11.2026, לפי שעה.
- `kp_3h_2021_2025_encoded.txt`: ‏Kp כל 3 שעות. כל תו הוא `Kp×3+65`.

**מקורות:**
- ‏Kp, כתמי שמש ו‑F10.7: ‏GFZ Potsdam.
- עננות וטמפרטורה: ‏Open‑Meteo, ‏ERA5.
- תחזית OVATION ורוח השמש: ‏NOAA SWPC.
- מפת העולם: ‏ECharts ו‑Natural Earth.

## כנות
- **קנה מידה:** המרחקים בחלל דחוסים לוגריתמית.
- **טבעת הזוהר:** מקורבת לפי מודל דיפול.
- **בזמן ההרצה:** השמיים הבהירים לפי ממוצע חודשי. בזמן הקפאה, לפי השעה המדויקת.
- **רוח השמש ו‑Bz:** מוצגים כמבנה ולא כנתון מדוד.
- **בדרום:** אין נתוני עננות, ולכן הרגעים שם הם "רגעים אפשריים" ולא שלמות מאומתת.
